# 咨询流程

## 公共输入

1. 接收用户输入。
2. 读取最近 20 条咨询历史。
3. 根据界面语言选择提示词和 RAG 工具。

## 第一次 API 调用：判断与关键词提取

模型判断问题是否与 DnD 相关。

### 未调用 RAG 工具

1. 使用第一次 API 返回的内容直接回复用户。
2. 不进行第二次 API 调用。

### 调用 RAG 工具

1. 从工具参数中读取一个或多个查询关键词。
2. 每组关键词分别进行向量检索。
3. 将检索结果、用户输入和历史消息交给第二次 API。
4. 第二次 API 流式生成最终回复。

## 公共收尾

1. 合并思考内容和正文。
2. 将用户输入与助手回复写入 SQL。
3. 在终端打印总耗时及两个 API 的 token 用量。
4. 向前端发送 `done`。
