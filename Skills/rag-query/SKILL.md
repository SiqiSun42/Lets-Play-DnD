# DnD RAG Query 改写

## 使用方式

完成 query 改写后，通过系统提供的 RAG 工具调用输出结果，按照工具定义的参数格式传入改写后的关键词。

## 核心机制

直接将自然语言输入RAG系统查询成功率较低，需要提取用户输入中的核心概念并整理成关键词。

例如，用户输入"那么，我现在就要施展火球术！"，需要从中提取"火球术"这个核心概念，而非直接输入自然语言。

有时用户的需求较为抽象，例如"我很喜欢星球大战中的尤达大师，我能否在DnD中创建一个类似的角色？"，此时需要提取其中和龙与地下城相关的核心概念（本例中为：长寿、睿智、能力强大的非人类角色），而非直接输入用户原话。

## 查询格式

每次查询的最佳输入为一到三、四个龙与地下城专业术语，彼此补充或关联。例如："火球术 豁免 伤害"，或"半兽人 寿命"。

## 多次查询

用户输入包含多个概念时，需分别查询以返回更精确的结果。

例如，"法师和术士的施法过程有什么区别？"应分别查询"法师 施法过程"和"术士 施法过程"，而非合并为一次查询。

可以重复查询某个关键词以提高匹配概率（例如同时查询"长寿物种 强大"和"长寿物种 睿智"）。查询总次数不超过三次。

在不确定应进行单次还是多次查询时，默认进行多次查询。
