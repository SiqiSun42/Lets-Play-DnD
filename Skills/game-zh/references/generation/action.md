# ③ 生成：游戏动作

本回合类别已确定为**游戏动作**（但不是战斗回合）：规则中的标准动作，或会产生明确游戏效果的正式行动——
使用道具、短休/长休、疾走、躲藏、施法等。

输出分三段：**开场 → 可选计算 → 结果**，最后可以加一条可选附注。

## 初步判断

先简单判断玩家的动作是不是游戏内合规动作、能不能在本回合正常推进。

如果不合规（例如玩家想使用自己没有的某个物品），**不推进动作**，
直接输出对玩家的提醒或指导即可。

## 数值从哪来

需要什么读什么，不要一次读所有人：

| 需要 | 读 |
|---|---|
| **行动者的状态**（HP、法术位、状态效果） | `status/` 下**这个行动者**的文件。玩家自己行动 → 读玩家角色（名字见 `current_info.json` 的 `current_player`）；让 NPC 队友做 → 读那个队友 |
| 用到或消耗物品 | `inventory.md` |
| 环境、地点相关 | 当前地点文档 |
| 规则细节 | 先读 `references/rule-query.md` 再调 `search_rules` |

**数值与效果只从本回合读到的面板与规则摘录里取。**
面板里没有给出的数值就是没有——不要凭空补一个，也不要凭记忆填。

## 要不要查规则

**游戏动作通常比属性检定更依赖规则**：物品效果、休息恢复、法术的作用方式、状态怎么结算，
这些往往不查就写不准。拿不准就查——不确定某个物品怎么算、不确定长休要恢复什么，都值得先读
`references/rule-query.md` 再调 `search_rules`。

查不到就按常见 5e 理解处理，并如实说明。

## 骰子

**不一定需要掷骰**。不需要数值结算的动作（疾走改变位置节奏、单纯宣告某个正式动作）跳过计算即可。

需要掷骰时，**用什么骰子看动作本身**，不一定是 d20：

- 治疗药水 → `1d4`（或按药剂强度 `2d4`）
- 休息恢复 → 生命骰
- 其他按规则或面板给出

调用 `roll_dice` 取值。**正文里出现的每个数值都要有来源**：
骰值来自 `roll_dice`，其余来自面板或规则摘录。

## 输出格式

### 第一段：开场

简洁生动地把玩家意图写成动作开始前的场景，用**第二人称**、以「你」起笔，
让玩家身临其境地感到角色正在执行这个动作。

### 第二段：计算（**只在有成败判定时**才写）

判断这一步是不是**判定**——有骰子、有成功与失败（例如某个效果要求一次豁免）。
是判定，就用引用块把过程写出来，方便玩家复核：

```
> 14（敏捷豁免骰，1d20）+ 2（熟练加值）= 16 ≥ 15（DC）
> 结果：成功
```

- 骰子要写来源与面数，例如 `14（敏捷豁免骰，1d20）`；多颗同面骰可写 `(3+2)（相关骰，2d6）`
- 其他数值同样标注，例如 `2（熟练加值）`、`15（DC）`
- 有多个不同的运算步骤时，可以写多组

**只是数值变化、没有成败判断的（喝药水回复、长休恢复），不用公式块**——
这类**规则层面**的变化放到 DM 附注里标准列出（见下）。

### 第三段：结果

把本回合的动作结果写成场景，语气贴合动作本身，**几句话到一两段**。

### 第四段：DM 附注（规则层面的变化）

**正文负责沉浸感，这里负责把规则层面的变化标准地讲清楚。**

只要本回合有规则层面的变化，就用引用块列出来：

```
> 生命值完全恢复；生命骰恢复一半（8 → 4）；法术位与特性按各自规则重置。
```

- **要列的**：HP、法术位、生命骰的恢复，获得或解除的状态，豁免的结论……
  这些光靠叙述传达不到——「你睡醒了觉得神清气爽」代替不了「生命值完全恢复」
- **不用列的**：不言自明的变化。药水少了一瓶、穿上铠甲、换一把武器，
  正文提到就够，不需要专门说明
- 不要写成场景描写——场景描写属于第三段
- 本回合确实没有规则层面的变化，就不写这一条

## 完整例子

以下仅供理解流程，勿照搬措辞。

### 有数值变化：喝治疗药水

玩家输入：「我喝下一瓶治疗药水。」

```text
你拔出腰间那瓶泛着淡红光泽的药水，拔开木塞一饮而尽，温热的药力立刻顺着喉咙散开。

药水化作暖流蔓延向四肢，肋下原本发闷的刺痛被一点点抚平，渗血的伤口缓缓收拢结痂。
你握了握拳，指节"咔"地作响——体力明显回升了几分。

> 生命值 7 → 10，已经满了。
```

### 有数值变化：长休

玩家输入：「我们在这里进行一次长休。」

```text
你裹紧斗篷躺下，海浪声和远处的兽嚎渐渐被涌上来的疲惫淹没。你放任自己坠入沉沉的黑暗。

当第一缕晨光从洞口漏进来、带着草木和露珠的气息时，你睁开了眼。一夜的休整让你感觉通体舒畅：
酸痛消散，旧伤结痂脱落，脑海中干涸的法术也重新充盈起来。你活动着肩颈站起身，
知道新的一天，可以满状态去迎战了。

> 生命值完全恢复；生命骰恢复一半（8 → 4）；法术位与特性按各自规则重置。
```

### 无计算：疾走

玩家输入：「我疾走冲向桥对面。」

```text
你深吸一口气，脚下的木板在重压下吱呀作响。

你猛地发力，碎石在靴后飞溅，桥栏边的缆绳随着你的狂奔而剧烈晃动。
当对岸的木板再次塌下一块时，你已经冲到了安全的区域。
```

### 无计算：准备战斗

玩家输入：「我们直接和这群半兽人开战！」

```text
面对这突如其来的袭击，你们的小队立刻拔出了武器；不需要商量，多年的默契让你们同时迈开步子。

半兽人们立刻发现了你们的存在。它们丢下还在冒泡的铁锅，抄起狼牙棒，龇牙咧嘴地朝你们咆哮起来。
战斗一触即发！
```

## 注意事项

- **本回合不是战斗推进回合。** 玩家做了明确的攻击或施法等战斗行为时，
  把它写成「战斗一触即发」，**不要在本回合展开交战结算**——互砍、扣血留给后续回合。
- **只写到本动作本身完成与否及其直接效果**，不要延伸到下一场景的新冲突。
  写到敌人发现你们、准备开战即可。
- 写到「战斗一触即发」为止。战斗初始化是紧接着的独立流程（尚未实现），这一回合不会真的打起来。

## 更新阶段

游戏动作**经常改面板**，是这五个类别里最常需要 ④ 阶段落盘的。常见情况：

| 本回合发生了什么 | 变更类型 |
|---|---|
| 喝药水、消耗物品、捡到东西 | 背包变更 |
| HP / 法术位 / 状态效果变化、长休恢复 | 状态变更 |
| 移动到别处 | 地点变更 |
| 同伴关系或设定发生持久变化 | 人物设定变更 |

④ 阶段按枚举逐条落盘，见 `references/update/plan.md`。
