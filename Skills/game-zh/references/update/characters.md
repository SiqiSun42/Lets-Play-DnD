# ④ 更新：人物设定

只处理 `characters/allies/<角色>.md`：外貌、性格、背景、动机、人物关系。

- 背包与金钱见 `references/update/inventory.md`
- 角色数值见 `references/update/status.md`
- 时间与地点见 `references/update/plan.md`

## 一般不改

**外貌、性格、动机、人物关系通常整个存档都不变。** 多数回合这里什么都不用做。

只有当本回合出现**永久性改变**时，才小幅修订：

| 可以改 | 不该改 |
|---|---|
| 外貌或身体特征发生永久变化（断臂、受咒印） | 一时的表情、临时的脏污 |
| 职业、身份、阵营的转变 | 一次性的表态 |
| 性格或动机发生质变（信念崩溃、立下誓言） | 一时的情绪起伏 |
| 重大事件导致的**关系**变化（结盟、决裂、亲人去世） | 一次口角 |

改的时候**小幅修订**，不要顺手把整份文档重写一遍。

## 怎么改

1. 先用 `read` 读那个角色的设定当前内容——覆盖之前必须先读
2. 用 `edit` 做精确替换，只动需要改的那几处
3. `edit` 的 `old_string` 要与文件原文**精确匹配**，且不能同时匹配多处

不产出给玩家看的文字。

## 例子

**该改**：正文写同伴莉娜因你抛弃了她哥哥而与你决裂 →
`characters/allies/莉娜.md` 里的人物关系一栏，把「信任」改成「敌视」。

**不该改**：正文写莉娜皱着眉头说了句气话 → 什么都不用改。

## 注意

- 拿不准是不是"永久性"时，**倾向于不改**——下个回合真的留下了痕迹，再改也不迟
- 改关系时，两边的设定若都写了这段关系，都要改（例如玩家角色的档案里也写了这层关系）
