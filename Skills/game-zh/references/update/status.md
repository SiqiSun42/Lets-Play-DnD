# ④ 更新：角色状态

只处理 `status/allies/<角色>.md`：HP、法术位、状态效果、装备带来的数值。

- 背包与金钱见 `references/update/inventory.md`
- 人物设定见 `references/update/characters.md`
- 时间与地点见 `references/update/plan.md`

**穿脱装备会同时牵动 `inventory.md`**——见 `plan.md` 的「联动」一节。

## 只看本回合已经发生的

只根据**本回合已经发生、并且已经写进正文或附注**的结果来改。不要预支下一回合，
不要凭空发明数值。

**只改本回合实际涉及的角色**，不要顺手把所有人的 status 都刷一遍。

## 怎么改

1. 先用 `read` 读**那个角色**的 status 当前内容——覆盖之前必须先读
2. 用 `edit` 做精确替换（改动小的时候），或用 `write` 整体重写
3. `edit` 的 `old_string` 要与文件原文**精确匹配**，且不能同时匹配多处

不产出给玩家看的文字。

## 改什么

| 变化 | 写进 status |
|---|---|
| HP 增减 | 当前 HP |
| 施法消耗、长休恢复 | 法术位 |
| 中毒、束缚、恐慌…… | 状态效果 |
| 学会新法术、获得新特性 | 对应的条目 |
| 使用物品导致的数值变化 | 相关字段 |

数值要与**附注里写明的变化**一致——附注说"生命值完全恢复"，status 里就该是满值。

## 穿脱装备

改 status 里的装备表、AC、属性修正。

**同时还要改 `inventory.md`**（装备表里的「是否装备」，新装备还要改负重），
**两边必须一致**。联动规则见 `plan.md` 的「联动」一节——一次想全再动手。

## 例子

**喝治疗药水**：正文写回复了生命 → 这里把当前 HP 改成新值。
（物品数量 −1 在 `references/update/inventory.md` 里改。）

**长休**：附注写"生命值完全恢复；法术位与特性按各自规则重置" →
这里把 HP 改成满值、法术位恢复、生命骰按规则恢复。

**穿上铠甲**：这里改装备表、AC、属性修正；同时去
`references/update/inventory.md` 改「是否装备」与负重。

## 注意

- 未在本回合正文或附注中成立的变化，不要写入
- 不要顺手改别人的 status
- 最容易漏的一处：**穿脱装备的另一边没改**
