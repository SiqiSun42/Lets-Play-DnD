# ④ 更新：背包与金钱

只处理 `inventory.md` 一个文件：物品数量、金钱、装备栏、负重。

- 角色数值（HP、法术位、状态效果）见 `references/update/status.md`
- 人物设定见 `references/update/characters.md`
- 时间与地点见 `references/update/plan.md`

**有几条规则会同时牵动别的文件**（穿脱装备、体能值变化）——见 `plan.md` 的「联动」一节。

## 只看本回合已经发生的

只根据**本回合已经发生、并且已经写进正文或附注**的结果来改。不要预支下一回合，
不要凭空发明没有出现过的物品或数值。

## 怎么改

1. 先用 `read` 读 `inventory.md` 的**当前**内容——覆盖之前必须先读
2. 用 `edit` 做精确替换（改动小的时候），或用 `write` 整体重写
3. `edit` 的 `old_string` 要与文件原文**精确匹配**，且不能同时匹配多处；
   片段尽量短而唯一，匹配失败这次更新就等于没做

不产出给玩家看的文字。

## 增减物品

玩家获得或失去物品、使用消耗品时：

- 增减数量；有「剩余次数」的物品相应扣减
- 用尽最后一次、或数量归零 → 删除该行
- **如果删的是表格里最后一个物品，保留空表格格式，不要连表格一起删掉**

## 负重

- 物品增减后，同步更新负重相关合计（总负重，以及是否超重的判断）
- **角色体能值变化时，最大负重也要跟着改**——最大负重是按体能值算的
  （体能值本身写在角色 status 里，见 `references/update/status.md`）

## 金钱

钱包金额与各币种数量保持自洽：花掉的钱要扣，收到的钱要加，
不能出现「付了钱但总额没变」或「币种折算对不上」。

## 例子

**捡到东西**：正文写明从尸体上搜到 3 枚金币和一把匕首 →
金币 +3、匕首加入物品表，负重相应增加。

**用掉消耗品**：正文写明喝下一瓶治疗药水 → 治疗药水数量 −1（或删行），负重相应减少。
（HP 的变化不在这里改，见 `references/update/status.md`。）

## 注意

- 未在本回合正文或附注中成立的变化，不要写入
- 表格格式要保住：列数、对齐、表头都不要动
- 最容易漏的两处：**空表格**、**负重合计**
