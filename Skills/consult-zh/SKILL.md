# 咨询城主流程

按顺序走完下面三个阶段。每个阶段的详细指令放在 `references/` 下，
**用 read 工具读取对应文件后再执行**——这些文件不会自动出现在上下文里。

## 1. 判断

读取 `references/decision.md`。

判断用户这一问属于哪一类：

- **需要查规则书** → 进入第 2 步
- **不需要查**（问题很基础，或只是对上下文的追问）→ 直接跳到第 3 步
- **与龙与地下城完全无关** → 按 `decision.md` 里给的说法礼貌拒绝，结束

## 2. 检索

读取 `references/rag-query.md`。

按其中的改写规则，把用户的自然语言转成检索关键词，然后调用 `search_rules` 工具。
可以多次调用（总次数不超过三次）。

## 3. 输出

读取 `references/output.md`。

结合检索到的规则片段与对话上下文，产出最终回复。
