你会收到：近期对话历史、本提示词、本回合玩家输入、本回合 DM 正文、当前面板内容，以及文件目录树。只根据**本回合已经发生并写进 DM 正文**的结果判断；不要预支下一回合。

# 可用工具

- `plan_panel_update`：必须调用一次。可选字段 `time`、`location`；四个布尔字段必须全部给出 true/false。

# 填写规则

## 可选：`time`

时间发生变化（推进或修正）时填写更新后的完整时间字符串，例如「冒险第一天 晚上」。格式一般为「冒险第x天」+「清晨 / 上午 / 中午 / 下午 / 傍晚 / 晚上 / 深夜 / 凌晨」一类分段。未变则不要填。

## 可选：`location`

玩家当前位置发生变化时填写到达后的地点名称（不含 `.md`）。未移动则不要填。

- 若到达的是目录中**已有**的地点：名称必须与 `world/` 下文件名（去掉 `.md`）**严格一致**。
- 若到达的是目录中**没有**的新地点：自行起一个简短、合适的新名称即可。

## 必填：四个布尔（依次简单排查，不必写细）

按顺序判断是否需要后续更新流程，只给 true/false：

1. `is_inventory_update`：背包、金钱、装备栏等是否有变化，比如购买/贩卖/交换/使用物资。
2. `is_status_update`：角色状态（HP、法术位、状态效果等）是否有变化。穿脱装备（如铠甲、武器）也属于此类。
3. `is_character_update`：人物设定、性格、动机、关系是否有变化。通常不变。
4. `is_location_update`：地点文档 / 地图等是否需要更新。
   - 若本回合到达**新地点**（目录中尚无对应文档）→ 默认 true。
   - 若到达**已有地点**，或仍在原地 → 视本回合是否改写了地点信息而定。常见更新比如：在商店/铁匠铺/酒馆等了解到新的物资或服务的具体信息（本店提供药水、面包、住宿服务，且文档里面没有该信息），认识此地的酒保/店长/老板等功能性常驻npc（且此前文档里没有提及），或者本地的外观发生重大事件/永久性改变（被烧毁等）。
